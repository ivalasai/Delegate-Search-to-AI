# Frozen numerical evidence

This pack contains 33 completed primary cells and three historical extended-horizon L1 cells, source-file checksums, parsed per-repeat L3 events, and numerical embedding vectors with roles and surrogate IDs. It omits source abstracts, extracted text, company and award metadata, raw model responses, prompts embedded in responses, run timestamps, and historical identifying Git SHAs. Frozen prompt templates remain separately available.

Parsed events retain tick, problem, repeat and parsed output. Existing analysis reconstructs modal choices and collision counts from those events. This verifies the calculations conditional on recorded parsing; it does not verify that raw responses were parsed correctly. Stored coupling similarities and vectors permit the existing analysis and reference graph computations; extraction and semantic adequacy are outside this replay's scope. These vectors are not represented as anonymized text or a substitute for source access.

The source is the SBIR public award-data service: https://www.sbir.gov/data-resources and https://www.sbir.gov/api . These services distribute award abstracts, but public access alone does not establish blanket redistribution rights for applicant-authored text. This package therefore distributes numerical research records rather than the abstracts. No blanket public-domain claim is made for SBIR texts, and no model-weight license is overridden. Source-text reproduction requires separate access and applicable terms.

The correction compares source-solution identities using each seed's mapping. The reference samples greedy matchings with fixed random seeds and is not uniform over matchings. It does not model timing or energy. Low overlap alone is not evidence of path dependence. The isolated below-interval comparison is exploratory and unadjusted.

Reference files in analysis/exports are untouched corrected exports. No scientific values were edited to make reproduction pass. The existing summary includes three historical 100-tick L1 records; they are not part of the 33-cell primary grid.
